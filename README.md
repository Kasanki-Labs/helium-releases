# Helium Solo releases

Installers and programs for [Helium Solo](https://helium-solo.pages.dev) by Kasanki Labs: record, replay, test and fix safe AI agents on your own machine.

Download them from [Releases](https://github.com/Kasanki-Labs/helium-releases/releases):

- `helium-solo-<version>-windows-x64-setup.exe`: the desktop app for Windows, with everything it needs.
- `helium-solo-<version>-windows-x64.zip` and `helium-solo-<version>-linux-x64.tar.gz`: the `helium` command-line program on its own.
- `SHA256SUMS.txt`: the checksum of each file.

To record an agent from Python you also need the package: `pip install helium-solo`.

The open recording SDK, the trace format and the verifier are in [Kasanki-Labs/helium-solo](https://github.com/Kasanki-Labs/helium-solo). Helium Solo is free to use under the terms in [TERMS.txt](TERMS.txt).
